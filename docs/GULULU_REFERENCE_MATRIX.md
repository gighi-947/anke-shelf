# 骨碌碌全能助手功能对照

基准：骨碌碌沉浸式全能助手 Beta V3.94（ScriptCat 5355）与公开阅读页
`/chat/48856`，核对日期 2026-08-15。仓库不保存第三方 userscript 源码，只记录公开协议、
可观察行为和本项目的验证入口。

## 范围约定

- AnkeShelf Windows 是离线优先的只读 EPUB 阅读器；完整复刻的合同是插件 Reader 路径，
  以及 Reader 对 Editor 生成协议的完整识别。
- Editor 写作工具和 Chat 图片压缩属于站点内容生产路径，Windows 阅读器不提供伪造入口；
  它们生成或影响阅读内容的部分必须兼容。
- 点赞、收藏、分享、举报依赖骨碌碌账号和站点写 API，不伪装成离线可用。书签使用
  AnkeShelf 本地书签等价实现。

| 秘密 / 线索 | 线索按书保存；CryptoJS/OpenSSL salted AES 兼容解密 | 完成；明文只进宿主弹窗 |

| 常驻停止音乐 | 音乐面板内停止按钮与正文停止标记 | 完成 |

| 视效 | 雨、雪、风、雷、震动、停止；视口中心和鼠标楼层触发 | 完成；遵守减少动态效果系统设置 |
| 夜间模式 / 暗色字修正 | AnkeShelf 主题与近黑/近白默认色映射 | 等价实现；保留作者显式彩色字 |
| 引用锚点 | `jumpFloorComponent` 及文本 `<引用 id floor>` | 完成；同书 EPUB 锚点，跨书回公开网页 |

| 返回/换书清理 | 停音乐、背景、视效、弹幕并清来源绑定 | 完成；NGA 隔离回归覆盖 |

## Editor 生成协议

| Editor 工具 | Reader 兼容结果 |
| --- | --- |

| 自定义文字颜色 | 安全 RGB/HEX 保留；危险样式拒绝 |
| 音乐 / 自动音乐 / 停止音乐 | 安全音乐语义标记与宿主播放器 |
| 视效 | 六类规范化视效 |
| 氛围背景 / 移除背景 | HTTPS 图片触发与清除标记，跨章继承 |
| 超级空行 | 标准空段落保留最小高度 |
| 引用跳转 | 同书内部锚点、跨书公开网页 |

## Chat 路径

Chat 的图片压缩面向发帖上传，不属于只读阅读器。Windows 导入链路已有独立图片在线、
内嵌、不含三态和格式/体积校验；不会在阅读页暴露“压缩并发帖”入口。
