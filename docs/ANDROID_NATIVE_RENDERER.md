# Android 原生渲染器（Kotlin/Compose 替代 WebView）

目标：阅读器（EPUB 与原生书）不再用 WebView 渲染，改为 Kotlin/Compose 原生排版，最终视觉（NGA 楼层/引用/骰子/表格/颜色/字体）与桌面端对齐。

## 从开发日志回顾的渲染坑（约束清单）

1. **分页几何（防右漏/防累积偏移）**：
   - 左右留白 P = min(margin, gap-8)，advance = colW + gap；下一列起点约在视口右缘外 8px，翻页后左缘是列间隙而不是上一列尾部；
   - 翻页步进必须用浏览器实际列宽（对应原生：用 TextMeasurer 实测的列宽），不能只信配置值；
   - 双页模式按屏幕宽高比判定（横屏且 1.2 ≤ 宽高比 ≤ 2.6 自动双页；竖屏/过方/超宽不双页）；双页列宽 <300 回退单页；
   - 超大章（纯文本 > 80 万字符）回退滚动模式，避免多栏布局内存爆炸。
2. **安全区/异形屏**：沉浸式隐藏系统栏时，顶部保留挖孔安全区约 3/8（可手动 dp 覆盖）；控制条显示时用 statusBarsPadding/navigationBarsPadding；正文上下留白 = 安全区 inset。
3. **模式切换**：滚动↔分页切换不得残留分页专用内联高度/列宽；滚动模式底部有「上一章/下一章」按钮，点正文两侧不换章。
4. **字体**：内置霞鹜文楷 26MB 必须从 assets 加载并缓存 Typeface；font-display 等价语义=首帧用系统字体渲染、字体就绪后重排；自定义字体走 fonts 目录。
5. **图片**：懒加载/异步解码；NGA 防盗链补 Referer/Cookie/UA；EPUB 图片按章节相对路径从压缩包读取；长按放大、右上角保存、不点空白退出、系统返回键退出。
6. **进度（text_offset）**：章内折叠纯文本字符偏移（与桌面 TextPos 同口径：标签间一个空格、空白折叠、首尾 trim）；滚动/翻页/换章/退出都要保存；每次保存立即落盘；换章竞态以当前章节为唯一真源；恢复用“offset → 段落锚点”，不用比例凑数。
7. **标注**：高亮按 text_offset 切 span 渲染；点已有高亮弹改色/笔记/删除；创建标注依赖选区能力（原生待做）。
8. **性能**：章节解析/分页计算放后台线程；滚动模式避免每帧重排；超大章按需惰性分页。
9. **视觉对齐桌面**：默认文字色跟随主题（深色页→浅色字），楼层内显式彩色字体保留；楼层卡片=1px 边框 + 4px 主题色左边条 + 圆角；引用块左边条 + 底色；骰子金色加粗；表格横向滚动。

## 架构

- `ui/reader/native/ReaderModel.kt`：XHTML → DOM → 块模型（楼层/段落/引用/骰子/表格/图片/评论），span 携带颜色/粗斜体。
- `ui/reader/native/NativeChapterView.kt`：滚动模式（Column + verticalScroll，偏移按块累加）与分页模式（TextMeasurer 按桌面几何切列/切页，页首偏移即进度锚点）。
- `ui/reader/native/NativeReaderScreen.kt`：页面壳（顶/底栏、目录、图片查看、进度保存、主题、安全区）。
- 数据层复用：`sanitizeReaderBody`、`PagedLayout`（几何）、`NgaFormatHtml` 色板、`EpubBook.readAsset`、进度存储。
