安科书架使用说明
================

一、书架
--------
· 导入 EPUB：书架右上角“+”→「导入 EPUB」；空书架也可直接点「导入 EPUB」。
· 从 NGA 下载：书架右上角“+”→「从 NGA 下载」，或空书架点「从 NGA 下载」。
· 排序与视图：页头可切换网格 / 列表视图，并按最近阅读、导入时间或名称排序。
· 更新与导出：NGA 书的封面（网格）或行尾（列表）有「更新」「导出」图标；
  EPUB 书提供「导出」，可保存原文件副本。
· 管理书籍：长按封面或列表行，弹出「重命名 / 删除」；删除会连同进度、
  下载断点与本地文件一起清除（有二次确认）。

二、NGA 下载（底栏“下载”）
--------------------------
· 登录配置：首次使用需填写 ngaPassportUid 与 ngaPassportCid，凭据只保存在本机，
  可在下载页“清除已保存配置”随时删除。
· 下载 / 更新：填写帖子 tid、只看楼主 uid（0=全部）、楼层上限、每章楼层数，
  并选择主题（浅色/深色）与图片（在线 / 内嵌 / 无图）；「内嵌」会把图片下载到
  本地并随书保存，离线也能看图，体积更大。
  - 同一帖子已下载过：再次操作默认走“增量更新”，只拉新楼层，可临时修改格式参数；
  - 点「重新下载」才是全量重下；
  - 更新完成后会收到通知 / Toast：已更新 X 楼、已是最新或失败原因。
· 已下载：与书架一样支持网格 / 列表两种视图；每本书有「更新」「导出」「删除」
  图标按钮，长按封面或行也可重命名 / 删除；导出 EPUB / Markdown 时文件名默认
  使用帖子原标题。

三、阅读器
----------
· 模式：底部栏可切换「分页 / 滚动」。分页模式点左右两侧翻页；
  滚动模式点两侧不会换章，滚到正文底部有「上一章 / 下一章」按钮。
· 字号与主题：底部栏 A- / A+ / 主题一键调整。
· 目录：点顶部「目录」，点面板外任意区域关闭。
· 图片：长按图片放大；放大页可双击 / 双指缩放、拖动平移，右上角可「保存」
  到自选位置；关闭请用右上角 × 或系统返回键。
· 标注：长按选择文字后，可加 6 色高亮、书签或笔记；点已有高亮可改色 / 编辑 / 删除。

四、进度保存（请务必了解）
--------------------------
· 分页模式：按“页码 + 段落”记录，退出 / 换章 / 退到后台都会立即保存，
  重新进入后回到对应页码。
· 滚动模式：以“屏幕正中间的正文文字”为进度锚点，滚动停止约半秒后自动保存，
  退出时也会立即保存。
  - 退出阅读器前，尽量让正文文字停留在屏幕正中间，进度最精确；
  - 如果当前屏幕正好全是图片（没有可见文字），会按“滚动比例”近似记录位置，
    重新进入后位置可能不是完全相同的图片，但仍会回到附近区域，不会回到章节开头；
  - 想精确续读时，建议先滚动到有文字的位置再退出。
· 正在加载 / 翻页动画尚未完成时退出，可能保留上一次已保存的位置；
  请等页面稳定（加载遮罩消失）后再退出。

五、设置
--------
· 外观：主题模式、亮度、预设色板、自定义背景 / 主题色 / 强调色 / 文字颜色，
  以及界面字号。
· 阅读：正文字体（内置霞鹜文楷 / 系统 / 导入字体）、字号、行高、页面宽度、翻页方式。
· 操作：点按区域、滑动翻页、音量键行为。
· 统计：阅读时长、会话、连续阅读；入口在「设置 → 统计」。
· 数据：数据目录、导出标注（MD / JSON）、清除所有数据。
· 帮助：内置使用说明与关于信息。

六、返回键
----------
· 系统返回 / 侧滑返回遵循页面层级：设置与下载的二级详情先回到一级菜单，
  再返回书架；统计返回设置；使用说明返回来源页；阅读器保存进度后返回书架；
  书架根页返回即退出应用。

七、隐私与数据
--------------
· 所有数据（书架、进度、设置、标注、统计、NGA 配置）都保存在应用私有目录，
  卸载应用或「清除所有数据」会一并删除。
· NGA 图片 / 接口请求仅携带必要的登录 Cookie，用于访问你订阅的内容。

八、小贴士
----------
· 阅读页顶 / 底栏会自动隐藏；点屏幕中间唤出，滚动 / 翻页一段距离后自动收起。
· 横屏且屏幕够宽时，分页模式会自动进入双页。
· 深色 / 羊皮纸主题下，默认文字颜色会随主题调整，帖子内的显式彩色字体保留原色。
· 阅读器顶栏章节名与底栏页码在深色背景下会跟随主题变色，不会出现黑字。
