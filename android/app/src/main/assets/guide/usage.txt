安科书架使用说明
================

一、书架
----
· 导入 EPUB：书架右上角“+”→「导入 EPUB」，从文件管理器选择即可。
· 从 NGA 下载：书架右上角“+”→「从 NGA 下载」，或空书架直接点「从 NGA 下载」。
· 排序：页头排序按钮，可按最近阅读 / 导入时间 / 名称。
· 视图：网格 / 列表可随时切换（页头图标）。
· 更新与导出：NGA 书的封面（网格）或行尾（列表）有「更新」「导出」图标；
  EPUB 书提供「导出」，可保存原文件副本。

二、NGA 下载与更新
----
· 首次使用需在「下载」页填写 Cookie：ngaPassportUid 与 ngaPassportCid，
  凭据只保存在本机，不会上传。
· 下载参数：楼层上限、分章楼数、主题（浅色/深色）、图片（在线/无图）。
· 下载/更新在前台服务中执行，可查看进度；再次下载同一帖子自动转为增量更新。
· 已下载的书支持导出 EPUB / Markdown（导出时文件名自动使用帖子原标题）。

三、阅读器
----
· 模式：底部栏可切换「分页 / 滚动」。分页模式点左右两侧翻页；
  滚动模式点两侧不会换章，滚到正文底部有「上一章 / 下一章」按钮。
· 字号与主题：底部栏 A- / A+ / 主题一键调整。
· 目录：点顶部「目录」，点面板外任意区域关闭。
· 图片：长按图片放大；放大页可双击/双指缩放、拖动平移、保存到自选位置；
  关闭请用右上角 × 或系统返回键。
· 标注：长按选择文字后，可加 6 色高亮、书签或笔记；点已有高亮可改色/编辑/删除。
· 进度自动保存，返回书架后从上次位置继续阅读。

四、设置
----
· 外观：主题模式、亮度、预设色板、自定义背景/主题色/强调色/文字颜色。
· 阅读：正文字体（内置霞鹜文楷 / 系统 / 导入字体）、字号、行高、页面宽度、翻页方式。
· 操作：点按区域、滑动翻页、音量键行为；界面字号在「外观 → 界面」。
· 统计：阅读时长、会话、连续阅读；统计入口在「设置 → 统计」。
· 数据：数据目录、导出标注（MD / JSON）、清除所有数据。

五、隐私与数据
----
· 所有数据（书架、进度、设置、标注、统计、NGA 库）都保存在应用私有目录，
  卸载应用或「清除所有数据」会一并删除。
· NGA 图片/接口请求仅携带必要的登录 Cookie，用于访问你已订阅的内容。

六、小贴士
----
· 阅读页顶/底栏会自动隐藏；点屏幕中间唤出，滚动/翻页一段距离后自动收起。
· 横屏且屏幕够宽时，分页模式会自动进入双页。
· 深色/羊皮纸主题下，默认文字颜色会随主题调整，帖子内的显式彩色字体保留原色。
