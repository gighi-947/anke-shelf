安科书架 · 发行版说明（v1.3.1）
========================

这是一个免安装的目录版发行包，已包含全部运行依赖：
Python 运行时、pywebview、EPUB 解析、NGA 帖子下载器
（httpx / ebooklib / curl_cffi / Pillow 等）。

系统要求：Windows 10/11、Edge WebView2 运行时（Win11 自带）、
.NET Framework 4.8（或更高版本）。

使用方法：
1. 将整个 AnkeShelf 文件夹解压到本地硬盘（建议不要放在
   压缩包内直接运行，也不要只把 exe 单独拷走）。
2. 双击 AnkeShelf.exe 即可运行，无需安装 Python。
3. 首次运行需要 Windows 10/11 自带的 WebView2 运行时
   （绝大多数新系统已内置；若提示缺少，可在微软官网免费安装）。
4. 用户数据（书架、进度、书签、下载缓存、NGA 配置等）保存在：
   %APPDATA%\AnkeShelf
   旧版 %APPDATA%\EpubReader 数据会在首次启动时自动迁移到新目录，
   书架、进度、标注与 NGA 配置都会保留。
5. 启动时窗口会在界面完全准备好后才出现（通常 1~3 秒），
   期间请勿反复双击或强制结束进程；若超过 12 秒仍未出现，
   请查看启动日志。

骨碌碌导入：
- 点击书架顶栏“下载安科”，默认进入“骨碌碌”页；粘贴书籍 ID 或
  https://www.gululu.world/book/<id> 链接后，点击“生成并导入”。
- 程序会分批获取公开楼层、生成标准 EPUB 并自动加入书架；可查看进度、
  取消任务或选择完成后直接打开。缓存位于
  %APPDATA%\AnkeShelf\gululu_library\<bookId>\post.epub。
- 书架 EPUB 默认只保留正文、标题、在线图片、折叠块、粗体/斜体/删除线和文字颜色。
  正式阅读器顶栏的评论按钮会按当前章节在线加载公开作品/楼层评论与子回复；结果缓存
  5 分钟，断网时明确显示最近缓存。评论面板中的“弹幕”开关只改变宿主层呈现，不改变
  正文分页和阅读进度坐标。
- 需要把评论交给其他 EPUB 阅读器时，在同一页面点击“导出含评论 EPUB”；程序会重新
  获取当前公开评论并把可折叠评论区写入独立文件，不修改书架中的紧凑 EPUB。
- 若正文包含骨碌碌作者工具生成的音乐、氛围背景或视效指令，顶栏会显示“音乐与氛围”
  按钮。正文音乐条可手动播放；自动音乐默认关闭，背景和动态视效可分别停用，音乐音量
  可调。系统启用“减少动态效果”时不会播放雨、雪、风、雷或震动动画。
- 音乐和背景仍从无凭据 HTTPS 外链在线加载；正文图片支持在线 / 内嵌 / 不含
  三种模式（导入时选择，默认在线）。已导入作品可在书架卡片点“检查更新”，
  只拉取末尾新增楼层；远端历史被删除、重排或替换时会要求完整重导。

NGA 下载：
- 首次使用请在“下载安科”面板的“配置”页填写 Cookie
  （ngaPassportUid / ngaPassportCid / User-Agent）并保存。
  获取方法（以 Edge/Chrome 为例）：
    1. 打开浏览器，访问 https://bbs.nga.cn 并登录你的账号；
    2. 按 F12 打开开发者工具；
    3. 切换到“应用程序”标签页（Firefox 为“存储”）；
    4. 左侧展开“Cookie”，点击 https://bbs.nga.cn；
    5. 在右侧列表中找到 ngaPassportUid（值是一串数字，即你的 NGA 用户 ID），
       双击“值”列复制；
    6. 再找到 ngaPassportCid（值是一串较长的字母数字，即登录会话凭证），
       双击复制；
    7. User-Agent 可点“默认填入”，或从开发者工具“网络”面板中任意一个
       NGA 请求的请求头里复制；
    8. 回到本软件“配置”页，把 uid、cid、UA 粘贴到对应输入框并保存。
  Cookie 过期后下载会提示需要登录或图片加载失败，重新复制一次即可。
  凭据只保存在本机 %APPDATA%\AnkeShelf\nga_config.ini，不会上传到任何服务器，
  不使用时可在“配置”页点击“清除已保存配置”，也请不要把 uid/cid 公开分享。
- 下载完成的帖子会自动转为 EPUB 并加入书架。
- 书架顶栏“下载安科”按钮打开下载 / 导出整合页：
  可发起下载并实时查看进度，也可选择已下载帖子按 EPUB / Markdown
  格式导出到自选文件夹（导出进度同样实时可见）。页面按
  “骨碌碌 / NGA / 更新 / 导出 / 配置”五个标签页组织，任务运行中对应标签
  会显示状态点；下载前会自动校验帖子 tid 与每章楼层数。
- 连载热更新：书架中带 NGA 徽章的卡片上有“检查更新”按钮，
  只拉取新增楼层并追加到本地书库，不重复下载旧内容；
  更新后继续阅读即可看到最新楼层，进度与标注不受影响。

自定义字体：
- 在阅读页“视图与排版”里可导入 .ttf/.otf/.ttc 字体文件，
  并分别设置全局字体与本书字体。
- 导入的字体保存在 %APPDATA%\AnkeShelf\fonts。

常用功能：
- 阅读时“排版”菜单可快速调字体、字号、行高、页面宽度；
  翻页方式支持整章滚动（默认，一章从顶滚到底即结束，不分页）、自动双页（横屏宽窗自动左右双页）、
  单页分页、强制横屏双页（左右两页并排，按整页跨翻页）；
  完整设置（主题、辅助、快捷键、数据等）在书架右上角齿轮进入。
- 设置 → 外观里可选择 9 套预设色板（默认、羊皮纸、夜间、Solarized、Nord、
  护眼绿、墨蓝等），也可以分别自定义背景色、主题色、强调色和文字颜色
  （点“默认”或“恢复跟随主题”回到主题默认）；切换即时生效，页面上方有
  阅读页实时预览。文字颜色只对默认黑/白文字生效，NGA 帖子的彩色字体保持原样。
- 主题模式支持浅色、羊皮纸、深色与“跟随系统”——跟随系统时会随 Windows
  深浅色设置自动切换；阅读页顶栏的主题按钮仍可快速循环主题。
- 设置页按“外观 / 阅读 / 辅助 / 快捷键 / 统计 / 数据”分栏，每个选项带简短说明；
  字号、行高、页面宽度与翻页方式也可以在“阅读”栏统一调整。
- 导出帖子时文件名默认使用安科标题（含非法字符会自动清理；无标题时用 tid 命名）。
- 下载 NGA 帖子时可填目录楼 pid 并选择目录用途：仅作索引（仍按每章楼层数
  分章，目录用于导出/索引）或兼作分章（按目录章节切分阅读章节）。
- NGA 帖子里超过一页高度的长表格（如角色卡、骰点表）会自动收纳为
  当前页内的滚动表格，楼层本身允许跨页拆分，保证双页/分页模式不再
  出现内容出界或页面错位。
- 设置页里可自定义快捷键（翻页、换章、主题、侧栏等）。
- 书架顶部有“最近阅读”横条，可一键回到最近读过的书；
  右上角可切换网格/列表视图，并按最近阅读、书名、作者或添加时间排序。
- 阅读页按 `?` 或点顶栏“?”按钮查看全部快捷键；`Ctrl+F` 直接打开全文搜索；
  `Esc` 关闭弹窗/菜单/侧栏；点击页面中央可随时隐藏或唤出顶栏与底栏。
- 全文搜索是独立整页：顶栏放大镜按钮或 `Ctrl+F` 打开。结果按章节分组，
  顶部显示全书命中总数与命中章节数；高频词每章最多先显示 50 条，
  点“显示本章更多结果”可逐批续取，靠后的章节不会被前面的结果挤掉。
  可勾选“大小写敏感 / 全词匹配”，搜索历史按书保存在本机（最多 10 条）。
- 顶栏的全屏按钮或 F11 可切换沉浸式阅读（软件全屏）；返回书架会自动退出，
  也可按 Esc 或 F11 退出，窗口恢复原尺寸。
- 阅读时点击正文图片可全屏放大，滚轮缩放、双击在适配与 1:1 之间切换，
  点击空白处或按 `Esc` 关闭。
- 书架中带 NGA 徽章的书籍卡片上有导出按钮，
  可选择 EPUB / Markdown 并自选保存文件夹。
- NGA 下载面板可随时“清除已保存配置”，删除本机 Cookie。
- “卸载并清除数据”会删除全部用户数据后退出程序；
  如需彻底卸载，清除后手动删除程序文件夹即可。

遇到问题：
- 若启动报错“无法启动 / Python.Runtime / .NET”：
  1) 从浏览器下载的 zip 请先右键 → 属性 → 勾选“解除锁定”，再重新解压运行；
  2) 安装或修复 .NET Framework 4.8（或更高版本）后重启本程序。
- 若程序无法启动或卡死，请删除 %APPDATA%\AnkeShelf\instance.lock 后重试。
- 若阅读时页面比窗口大、内容错位或需要拖动滚动条居中：程序已默认锁定
  浏览器缩放为 100%（Ctrl+滚轮不会误触缩放），重启程序即可恢复。
- 启动日志保存在 %APPDATA%\AnkeShelf\logs\startup.log，
  反馈问题时把该文件一并提供，能帮助我们快速定位。
